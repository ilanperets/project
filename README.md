# מערכת כתבי כמויות

מערכת web (מחשב וטאבלט) שמקבלת תוכניות PDF, מזהה אותן, מודדת כמויות, בונה כתב כמויות היררכי,
מפרקת אותו לחומרים להזמנה, ומנהלת תמחור, חשבונות חלקיים והצעות מחיר.

## הרצה
    pip install -r requirements.txt
    python3 -m app          # נפתח ב-http://127.0.0.1:8000

הנתונים נשמרים בתיקיית `data/` (לא נכנסת לגיט). בהרצה ראשונה המערכת ריקה לגמרי.
משתנה סביבה `KAMUYOT_DATA` מחליף את מיקום התיקייה. לשימוש מהטאבלט ברשת המשרד: להריץ עם host 0.0.0.0.

## מבנה
- `app/classify.py` זיהוי סוג גיליון ולמידה מתיקונים (data/rules.json)
- `app/engines.py` מנועי מדידה: כלונסאות, קירות, גג, פתחים, חללים
- `app/boq.py` בניית כתב היררכי (NN.SS.IIII), פריטים צפויים, "מה חסר", ייצוא Excel
- `app/brain.py` הנחות, פירוק לחומרים, זיכרון מחירים, חשבון חלקי
- `app/server.py` ה-API ושירות המסך
- `app/static/index.html` המסך

## הפעלה על מחשב או אייפד

**על מחשב (Windows/Mac), לבדיקה מהירה:** `pip install -r requirements.txt playwright && playwright install chromium`, ואז `python -m app`. פותחים `http://localhost:8000`. מאייפד באותה רשת Wi-Fi פותחים `http://<כתובת-המחשב>:8000`.

**שרת באינטרנט (גם לאייפד מכל מקום):** המאגר כולל `Dockerfile` ו-`render.yaml`. ב-Render בוחרים New → Blueprint, מחברים את המאגר, וקובעים שני משתני סביבה: `MIDA_ADMIN_EMAIL` ו-`MIDA_ADMIN_PASSWORD`. הם יוצרים את מנהל הפלטפורמה (אתה). הנתונים נשמרים בדיסק `/srv/data`.

**חברות ומשתמשים (MIDA):** כשמוגדר `MIDA_ADMIN_PASSWORD` (או `MIDA_AUTH=1`) המערכת דורשת כניסה. מנהל הפלטפורמה נכנס, פותח "ניהול פלטפורמה" ויוצר לקוחות. לכל חברה תיקייה משלה (`/srv/data/orgs/<id>`), והיא לא רואה נתונים של אחרות. אפשר לעצור או להפעיל חברה, לשנות מסלול ותוקף, ולהיכנס לחברה במצב תמיכה (נרשם ביומן). בלי המשתנים האלה המערכת עובדת כמו קודם: משתמש אחד ובלי כניסה. בדיקות: `python tests/test_auth.py`.
