# וילה איבגי – כתב כמויות ראשוני

- `villa_ivgi_quantities.xlsx` – טבלת הכמויות המסכמת (סטטוס לכל שורה: נמדד / חלקי / דורש השלמה).
- `villa.json`, `piles.jpg` – הנתונים והתמונה שמוטמעים במסך "וילה איבגי" ב-`kamuyot_engine_demo_v4.html`.
- `measure_walls.py` – מדידת אורכי קירות לפי עובי משכבת WL (גיליונות A1–A3, קנ"מ 1:50).
- `villa_data.py`, `make_xlsx.py` – שורות הכתב ויצירת האקסל.

נמדד בביטחון: 27 כלונסאות (21 Ø50, 6 Ø60) מ-kon7-1. שאר הסעיפים חלקיים או ממתינים (OCR של מפלסים וברזל, מיפוי גיליונות תקרה, תוכנית אדריכל מלאה).
